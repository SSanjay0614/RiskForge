# What the interface needs on the EC2 host, which is six packages rather than the
# root requirements.txt's twenty.
#
# The difference is the whole argument for Phase 12: the app on this instance does
# not answer questions, it asks one. A question goes to the Step Functions state
# machine, the model calls happen in three Lambdas, the scoring happens in Fargate
# against two SageMaker endpoints, and the answer comes back as one JSON document
# of aggregates. So nothing here needs langgraph, langchain, pydantic, xgboost,
# scikit-learn or joblib -- about 1.5 GB of wheels and roughly thirty seconds of
# import time that a t3.small does not have to spend.
#
# It also means no model artifact, no database driver and no API key on this host.
# There is nothing on the instance to read: the credentials it holds are an
# instance role that may start one state machine and describe one execution.
#
# Python 3.9, matching the AL2023 default and the version in the root
# requirements.txt, so the two files cannot disagree about a wheel.
